# 🐍 Snake Arena

Snake.io 스타일의 브라우저 게임이에요. `index.html` 파일 하나로 실행되며, 별도 설치나 라이브러리가 필요 없어요.

## ▶️ 플레이하기

**https://bjh966700-tech.github.io/snake-arena/**

또는 `index.html`을 내려받아 브라우저로 열면 바로 플레이할 수 있어요.

## 🎮 조작 방법

| 환경 | 방향 조종 | 부스트 |
|------|-----------|--------|
| PC | 마우스 이동 | 클릭 또는 스페이스바 길게 누르기 |
| 모바일 | 화면 터치 | 왼쪽 아래 BOOST 버튼 |

## 📜 규칙

- 먹이를 먹으면 몸이 길어지고 굵어져요.
- 머리가 다른 뱀의 몸이나 맵 경계(빨간 테두리)에 닿으면 게임 오버예요.
- 내 몸으로 상대의 길을 막아 쓰러뜨리면, 상대의 몸이 큰 먹이로 흩어져요.
- 부스트를 쓰면 빨라지지만 길이가 조금씩 줄어요.

## ✨ 기능

- AI 뱀 22마리 (먹이 탐색, 장애물 회피, 플레이어 사냥)
- 실시간 리더보드 · 미니맵
- 처치 수 · 순위 표시, 개인 최고 기록 저장
- PC · 모바일 모두 지원

## ⚙️ 설정 바꾸기

`index.html` 안의 값을 바꾸면 난이도를 조절할 수 있어요.

- `BOT_COUNT` — AI 뱀 수 (기본 22)
- `WORLD_R` — 맵 반지름 (기본 3000)
- `FOOD_COUNT` — 먹이 개수 (기본 1700)
